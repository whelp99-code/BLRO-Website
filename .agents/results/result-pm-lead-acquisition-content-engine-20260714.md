# BLRO 검색·콘텐츠·상담 전환 엔진

## 목표

HCI, 가상화, VDI, 보안, DR, SASE를 검토하는 고객이 검색·콘텐츠·외부 채널을 통해 BLRO에 유입되고, 전환 진단 상담 또는 체크리스트 요청으로 이어지며, 영업 결과가 다음 콘텐츠 주제로 되돌아오는 90일 운영 체계를 만든다.

## 우선순위

1. **1~2주: 기술 SEO와 측정 기반**
   - 운영 도메인, canonical, robots, sitemap, JSON-LD
   - Google Search Console·네이버 서치어드바이저 등록
   - UTM·이벤트 사전·개인정보 동의 기준
2. **3~4주: 실제 전환 경로**
   - 안전한 상담 접수 API와 Slack/CRM 전달
   - 솔루션별 상담 CTA, 체크리스트 다운로드, 접근성·모바일 검증
3. **5~8주: 콘텐츠 재활용 체계**
   - 5개 검색 클러스터와 12주 편집 캘린더
   - 원문 1건 → 네이버 요약 → LinkedIn → YouTube → Threads/Instagram 포맷
4. **9~12주: 파일럿 검증과 영업 피드백**
   - 웹사이트·네이버·LinkedIn·YouTube만 핵심 채널로 운영
   - 유효 미팅과 기회 생성 기준으로 채널·주제·CTA를 조정

## 운영 원칙

- 매일 2건의 리서치는 초안 풀이다. 공개는 사람이 검토·승인한 주 2~3건으로 제한한다.
- 모든 외부 콘텐츠는 BLRO 원문 URL과 하나의 분명한 CTA로 돌아온다.
- Threads와 Instagram은 브랜드 확산용이며 90일 핵심 리드 KPI 채널이 아니다.
- 리드 수만 최적화하지 않는다. 유효 미팅과 기회 생성까지가 성공 기준이다.

## 사용자 결정이 필요한 항목

1. 운영 도메인과 도메인 소유자
2. 상담 문의 수신처: Slack, CRM 또는 이메일
3. 90일 우선 고객 세그먼트: 제조, 공공, 의료, 금융, 일반 엔터프라이즈 등
4. 첫 체크리스트 주제: VMware 전환/HCI, 랜섬웨어 복구, VDI, SASE 중 선택

## 계획 검증

- 모든 구현 작업에 테스트·보안·개인정보 기준을 포함했다.
- 외부 계정 연결과 개인정보 수집은 별도 승인 게이트로 분리했다.
- 외부 채널을 넓히기 전에 웹사이트 원문·전환·측정을 선행하도록 의존성을 구성했다.
