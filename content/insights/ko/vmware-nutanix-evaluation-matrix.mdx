## 핵심 주장

초안은 VMware와 Nutanix의 우열을 결론내리지 않으며, 현재 환경의 워크로드·운영·복구·전환·계약 조건을 확인하는 PoC 검토표로만 사용합니다.

근거와 결정: 현재 문서에 제시된 내부 검토 범위와 평가 항목을 근거로, 공식 문서·계약 조건·PoC 결과가 확보될 때만 전환·유지·추가 검증을 결정합니다.

## 주장과 근거

| 주장 또는 결정 | 근거 | 운영 조치 |
| --- | --- | --- |
| 제품 우열이나 기능 결론을 공개하지 않는다 | 문서의 내부 검토용 상태와 공개 전 필수 검토 조건 | 공개 웹사이트·sitemap·목록에 노출하지 않음 |
| 비교는 동일한 기간·범위의 증거로 판단한다 | 문서의 비용·계약 및 PoC 검증 항목 | 지원 정책, 계약 조건, PoC 결과와 가정 목록을 확인 |

## 배포 상태

문서는 내부 검토용 초안입니다. 공개 웹사이트, sitemap, 목록, 관련 콘텐츠 링크에 노출하면 안 됩니다. 벤더 기능, 라이선스, 가격, 호환성, 성능 또는 지원 범위에 관한 결론은 계약 조건과 현재 공식 문서, PoC 결과를 확인한 뒤에만 작성합니다.

## 비교의 출발점

비교 대상의 이름보다 현재 환경이 필요한 운영 결과를 먼저 정의합니다. 아래 항목은 제품 우열을 단정하기 위한 점수표가 아니라, 고객 환경에 맞는 검증 계획을 만들기 위한 질문 목록입니다.

## 평가 매트릭스

| 평가 영역 | 확인 질문 | 검증 증거 |
| --- | --- | --- |
| 워크로드 적합성 | 핵심 업무, 운영체제, 데이터베이스와 주변 도구가 지원 조건에 맞는가 | 벤더 지원 정책, 호환성 목록, PoC 결과 |
| 운영 모델 | 일상 운영, 패치, 증설, 장애 대응을 현재 팀이 수행할 수 있는가 | 운영 절차 리허설, 역할 분담표 |
| 가용성과 복구 | 장애도메인, 백업, 복제와 복구 목표가 업무 요구와 맞는가 | 장애 시나리오, 복구 훈련 기록 |
| 전환 난이도 | 마이그레이션 순서, 다운타임, 롤백과 데이터 정합성을 관리할 수 있는가 | 전환 runbook, 파일럿 결과 |
| 비용과 계약 | 라이선스, 유지보수, 인프라, 운영 인력의 총 조건을 같은 기간과 범위로 비교했는가 | 유효 견적, 계약 조건, 가정 목록 |
| 생태계 연동 | 백업, 보안, 네트워크, 모니터링, 자동화 도구와의 책임 경계가 명확한가 | 연동 테스트, 공급자 책임표 |

## 검토 절차

1. 고객의 현 가상화 환경과 업무 우선순위를 기록합니다.
2. 후보별 필수 요건과 제외 조건을 합의합니다.
3. 대표 워크로드와 장애·복구 시나리오로 PoC 범위를 정합니다.
4. 결과와 가정을 검토해 전환, 유지 또는 추가 검증을 결정합니다.

## 공개 전 필수 검토

- 최신 공식 문서와 계약 조건 재확인
- 가격, 지원 범위, 성능, 호환성 표현의 근거 확보
- 벤더와 고객 관련 비공개 정보 제거
- 기술 검토자와 publication approver의 승인
