## 한눈에 보기

Model Router What's New는 2026년 8월에 28개 리전, 버전 2025-11-18의 27개 모델, 에이전트 요청의 오픈소스와 Anthropic 선택을 안내합니다. 개념 문서의 리전 표는 Data Zone Standard가 없는 리전을 남깁니다.

- 결정: 기본 풀을 둘지, 과제별 부분 집합과 라우팅 모드를 둘지, Claude를 따로 배포할지
- 전제: Claude는 카탈로그에서 먼저 배포해야 라우터가 호출한다고 개념 문서와 에이전트 안내가 적는다
- 불일치: 8월 What's New는 28개 리전 모두 Data Zone Standard를 지원한다고 적고, 개념 문서 표는 일부 리전을 Global Standard만 표시한다
- 범위: 에이전트 게시 신원이나 거버넌스 프레임워크가 아니라 라우팅 풀과 리전 경계

## 문제 상황

에이전트 하나를 라우터 배포에 붙이면 요청마다 모델이 바뀝니다. 풀에 어떤 모델이 있고, 어느 리전에서 Data Zone을 쓸 수 있는지는 같은 8월 안내 안에 어긋납니다.

8월 What's New는 라우터가 28개 Azure 리전에서 Global Standard와 Data Zone Standard를 모두 지원한다고 적습니다. 같은 달 날짜의 개념 문서는 브라질 남부, 캐나다 동부, 남아프리카 북부, 스위스 서부, 영국 남부·서부, 미국 중서부를 Data Zone 없음으로 표시합니다. 한국 중부는 둘 다 있습니다.

8월 갱신은 gpt-5.6-sol, gpt-5.6-terra, gpt-5.6-luna, claude-opus-4-8을 넣고 gpt-5-chat, gpt-5.2-chat, gpt-5.3-chat, DeepSeek-V3.1, claude-opus-4.1을 뺍니다. 기본 풀이면 추가 조치가 없고, 예전 제거 모델이 들어 있는 부분 집합은 바꿔야 한다고 적습니다. 5월 What's New는 같은 버전이 28개 모델을 지원한다고 적었고, 8월은 27개입니다.

에이전트 안내는 도구가 붙은 요청에서 적격 OpenAI, 오픈소스, Anthropic만 고르고, 도구와 배포 구성이 맞아야 한다고 적습니다. 컨텍스트 창은 가장 작은 하위 모델로 제한됩니다.

## 지금 결정할 것

- 기본 풀을 둘지, 과제별 부분 집합을 둘지
- Balanced, Quality, Cost 중 어떤 모드를 쓸지
- Claude를 리소스에 따로 배포한 뒤 풀에 넣을지
- Global Standard와 Data Zone Standard 중 무엇을 전제로 할지
- 자동 업데이트를 켜서 하위 모델 변경을 받아들일지

## 의사결정 기준

### 기본 풀과 과제별 부분 집합을 한 승인으로 두지 않습니다

개념 문서는 새 기반 모델이 나와도 포함 목록에 넣지 않으면 부분 집합에 들어가지 않는다고 적습니다. 에이전트 안내는 연구, 일반, 분류용으로 배포를 나누라고 적습니다. 컴플라이언스 목록이 있으면 부분 집합을 먼저 적습니다. 기본 풀은 제거·추가가 배포에 바로 반영됩니다.

### 8월 리전 문장과 개념 표 중 운영 페이지를 고릅니다

What's New는 28개 리전 모두 Data Zone을 지원한다고 적습니다. 개념 문서 표는 7개 리전을 Global만 표시합니다. 데이터 상주가 필요하면 개념 표의 Data Zone 칸을 다시 엽니다. 한국 중부는 표에서 둘 다 있습니다.

### Claude 배포와 라우터 배포를 한 작업으로 보지 않습니다

개념 문서와 에이전트 안내는 Claude를 먼저 배포해야 라우터가 호출한다고 적습니다. 다른 지원 모델은 따로 배포하지 않아도 됩니다. Claude를 풀에 넣겠다는 승인에는 별도 배포와 도구·리전 호환 확인을 붙입니다.

### 자동 장애 조치와 승인 목록을 맞춥니다

개념 문서는 기본 배포에서 장애 조치가 켜져 있고, 사용자 지정 배포는 부분 집합이 대체 집합이라고 적습니다. 모델을 하나만 두면 대체 경로가 없습니다. 자동 업데이트를 켜면 하위 모델과 비용 특성이 바뀔 수 있다고 적습니다.

## 실무 체크리스트

1. 대상 에이전트가 도구 호출을 쓰는지, 일반 대화만 쓰는지 나눕니다.
2. 라우터 버전이 2025-11-18인지, 동결된 이전 버전인지 확인합니다.
3. 부분 집합에 8월에 빠진 모델이 남아 있는지 점검합니다.
4. Claude를 쓸 과제만 별도 배포와 풀 포함을 적습니다.
5. 리전의 Global과 Data Zone 지원을 개념 표로 다시 엽니다.
6. Balanced, Quality, Cost와 최소 두 개 모델 대체 가능 여부를 적습니다.
7. 자동 업데이트 허용 여부와 하위 모델 변경 승인자를 정합니다.
8. 응답의 model 필드로 실제 선택된 모델을 남길지 정합니다.

## 제외 범위

- 에이전트 게시 신원과 도구 호출 주체를 다루는 기존 글을 다시 쓰는 범위
- AI 운영 거버넌스 프레임워크를 다시 쓰는 범위
- 특정 모델, 라우팅 모드, 공급자의 우열이나 가격 비교
- 라우터가 품질, 지연, 비용 절감을 보장한다는 주장
- 고객별 규제 적용, 라이선스, 계약 해석의 확정 판정
