## 한눈에 보기

Prisma Access 6.2 소프트웨어 전제 문서는 Preferred가 dataplane 11.2.7-h17을 쓰고, Innovation은 PAN-OS 12.1.8을 쓴다고 적습니다. 같은 표는 Innovation dataplane 12.1.8을 coming soon으로 둡니다.

- 결정: Preferred 11.2.7-h17만 올릴지, Innovation 12.1.8이 필요할 때까지 기다릴지
- 전제: Innovation dataplane 업그레이드는 선택이며, 그 dataplane이 필요한 기능을 쓸 때만 요구된다
- 운영 책임: Panorama면 Cloud Services plugin 올리는 시점을 운영자가 정하고, 인프라 업데이트는 Palo Alto Networks가 사전 안내와 함께 관리한다
- 범위: Secure Agentless Access 경계 글의 재작성이 아니다. 6.2 8월 항목의 SAA와 RBI는 포인터만 둔다

## 문제 상황

6.2를 올렸다고 보고하면, Preferred 기준 dataplane과 coming soon Innovation, 벤더가 올리는 인프라가 한 승인에 섞입니다.

새 기능 페이지는 2026-08에 App Security와 WAF 통합, SASE Resilience의 Cloud Identity Engine과 Enterprise DLP 미국 초기 롤아웃, Panorama와 Strata Cloud Manager의 Service Connection·Remote Network Native IPv6, Secure Agentless Access용 Web Application Isolation을 적습니다. 공개 웹 앱의 Remote Browser Isolation은 필수이며 기본으로 켜진다고 적습니다. 이 글은 그 SAA와 RBI를 6.2 8월 기능 포인터로만 남기고, 에이전트 없는 앱·라이선스 결정은 기존 글의 범위로 둡니다.

소프트웨어 전제 문서는 6.2 Preferred 기준을 PAN-OS 11.2.7-h17, Innovation을 PAN-OS 12.1.8 coming soon으로 적습니다. Innovation dataplane 업그레이드는 선택이며 그 기능이 필요할 때만 요구된다고 적습니다. 같은 페이지 아래는 Prisma Access 6.2 Preferred가 PAN-OS xx.x.x-xx이고 6.1 Innovation이 PAN-OS 12.2라는 문장도 있습니다. 표의 11.2.7-h17·12.1.8과 이 문장을 하나로 합치지 않습니다.

릴리스 정보 페이지는 인프라 업데이트를 Palo Alto Networks가 관리하고 사전 안내를 준다고 적습니다. Panorama로 관리하면 새 기능을 쓰는 Cloud Services plugin을 언제 올릴지 운영자가 정합니다. End-of-Life가 아닌 GlobalProtect는 쓸 수 있고, 6.2에는 권장·필수 버전이 따로 있습니다.

## 지금 결정할 것

- 이번 창을 Preferred 11.2.7-h17로 둘지, Innovation 12.1.8이 더 이상 coming soon이 아닌 뒤에 갈지
- Innovation dataplane이 필요한 기능이 있는지, 없으면 올리지 않을지
- Panorama면 Cloud Services plugin 6.2를 언제 승인할지
- 인프라 업데이트 사전 안내 창을 내부 변경과 맞출지
- SAA와 RBI 8월 항목을 기존 SAA 글과 섞지 않을지

## 의사결정 기준

### Preferred 기준과 Innovation coming soon을 같은 일반 공급으로 보지 않습니다

전제 문서는 Preferred 기준을 11.2.7-h17로 두고 Innovation 12.1.8을 coming soon으로 적습니다. coming soon을 이미 쓸 수 있는 일반 공급으로 보고하지 않습니다. 아래 문장의 xx.x.x-xx와 6.1 Innovation 12.2도 표와 같이 남깁니다.

### Innovation dataplane은 기능이 필요할 때만 올립니다

전제 문서는 Innovation dataplane 업그레이드가 선택이며, 그 dataplane이 필요한 기능을 쓸 때만 요구된다고 적습니다. 6.2라는 이름만으로 12.1.8 창을 열지 않습니다.

### 인프라 업데이트와 plugin 승인을 한 일정으로 보지 않습니다

릴리스 정보는 인프라 업데이트를 벤더가 사전 안내와 함께 관리한다고 적습니다. Panorama 운영자는 plugin을 언제 올릴지 정합니다. 벤더 인프라 창이 열렸다고 plugin과 Innovation dataplane이 끝난 것으로 보지 않습니다.

### SAA와 RBI는 포인터만 남깁니다

8월 새 기능은 Secure Agentless Access의 Web Application Isolation과 공개 웹 앱 RBI 기본 적용을 적습니다. 어떤 앱을 에이전트 없이 줄지는 기존 SAA 글의 결정입니다. 이 글은 6.2 Preferred와 Innovation 경로만 가릅니다.

## 실무 체크리스트

1. 현재 Prisma Access가 Strata Cloud Manager인지 Panorama인지, 지금 dataplane을 기록합니다.
2. 목표가 Preferred 11.2.7-h17인지, Innovation 12.1.8인지 나눕니다.
3. 12.1.8이 아직 coming soon이면 Innovation 창을 보류할지 승인자를 적습니다.
4. Innovation dataplane이 필요한 기능 목록이 있는지 전제 문서와 대조합니다. 없으면 Preferred만 남깁니다.
5. Panorama면 Cloud Services plugin 6.2 승인 날짜와 담당자를 정합니다.
6. 인프라 업데이트 사전 안내를 내부 변경 창에 넣을지 기록합니다.
7. 6.2 권장·필수 GlobalProtect 버전을 현재 단말과 대조합니다. EoL이 아닌 버전은 지원된다고 적혀 있습니다.
8. SAA와 RBI 8월 항목은 기존 SAA 글로 넘기고 이 승인에 섞지 않습니다.

## 제외 범위

- Prisma Access SAA 에이전트 없는 경계 글의 재작성
- Prisma SD-WAN ION 양자내성 글의 재작성
- 12.1.8 coming soon을 일반 공급으로 보는 해석
- SASE 제품의 우열, 가격, 성능 비교
- 고객별 테넌트, 계정, 웹훅의 공개
