## 한눈에 보기

CVE-2026-21962는 Oracle HTTP Server와 WebLogic Server Proxy Plug-in의 접근 제어 오류입니다. 인증 없이 HTTP로 프록시를 장악할 수 있고, 범위가 바뀌어 뒤쪽 제품에도 영향을 줄 수 있습니다. CISA는 2026-08-24에 Known Exploited Vulnerabilities Catalog에 올렸습니다.

- 영향 제품: Oracle HTTP Server와 Apache용, IIS용 WebLogic Server Proxy Plug-in
- 영향 버전: 12.2.1.4.0, 14.1.1.0.0, 14.1.2.0.0. IIS 플러그인은 12.2.1.4.0만
- 우선 판단: 인터넷에 열린 HTTP 프록시, DMZ 배치, January 2026 Critical Patch Update 적용
- 범위 한계: BOD 26-04의 기한과 의무는 미국 Federal Civilian Executive Branch에만 적용된다

## 문제 상황

가장자리 HTTP 프록시를 WebLogic 버전 번호만으로 일괄 패치하면, 인터넷에 열린 listen socket과 내부 전용 프록시가 같은 긴급도에 섞입니다.

Oracle January 2026 Critical Patch Update와 NVD는 이 취약점을 Weblogic Server Proxy Plug-in for Apache HTTP Server와 IIS에서, 인증되지 않은 공격자가 HTTP로 쉽게 악용할 수 있는 문제로 설명합니다. CVSS 3.1 기본 점수는 10.0이고 가용성 영향은 없습니다. 범위는 Changed입니다. Oracle Note 1은 IIS 플러그인 영향 버전을 12.2.1.4.0만으로 한정합니다.

CISA 경보는 2026-08-24에 이 CVE 한 건을 KEV에 올렸다고 적습니다. KEV 카탈로그 항목의 추가일은 2026-08-24, 조치 기한은 2026-08-27입니다. NVD KEV 표도 기한을 2026-08-27로 둡니다. 같은 NVD 변경 이력에는 KEV 필드가 붙을 때 기한이 2026-08-24로 기록된 줄이 있습니다. 운영 일정은 카탈로그 항목을 다시 연 날짜를 기록합니다.

KEV 항목의 Required Action은 벤더 지침을 따르고, 클라우드 서비스에는 BOD 22-01 안내를 따르거나, 완화책이 없으면 사용을 중지하라고 적습니다. BOD 26-04는 2026-06-10에 BOD 22-01을 폐지했다고 적습니다. 미국 연방 일정은 BOD 26-04를 열고, 패치 내용은 Oracle CPU를 엽니다.

## 지금 결정할 것

- 인터넷에서 도달할 수 있는 Oracle HTTP Server와 WebLogic 프록시를 호스트별로 목록화할지
- Apache 플러그인과 IIS 플러그인을 버전별로 나눌지. IIS는 12.2.1.4.0만 영향
- 프록시를 유지할 장비는 January 2026 CPU를 언제 적용할지
- 더 이상 쓰지 않는 가장자리 HTTP는 끌지
- 미국 연방 기관이 아닌 조직에서 BOD 26-04 기한을 내부 마감으로 쓸지, KEV 등재만 우선순위 신호로 볼지

## 의사결정 기준

### 인터넷 노출과 플러그인 종류를 먼저 가릅니다

Oracle과 NVD는 네트워크 HTTP로 인증 없이 프록시를 장악할 수 있다고 적습니다. 인터넷에 열린 DMZ 프록시와 내부만 듣는 프록시를 같은 긴급도로 보지 않습니다. Apache 플러그인과 IIS 플러그인을 한 패키지로 묶지 않습니다.

### 고정 조치는 January 2026 CPU입니다

Oracle advisory는 이 CVE를 Fusion Middleware의 January 2026 Critical Patch Update에 넣습니다. 한 누적 패치를 모든 Fusion Middleware에 같다고 보지 말고, HTTP Server와 Proxy Plug-in 패치 문서를 엽니다. 서비스를 끄는 결정은 취약점을 고친 상태가 아니라 노출을 줄이는 운영 선택입니다.

### IIS 버전 한정을 표에서 빼지 않습니다

영향 버전 세 칸을 그대로 IIS에 옮기지 않습니다. Oracle Note 1과 NVD 설명은 IIS 플러그인을 12.2.1.4.0만 영향으로 둡니다. 14.1.x IIS 플러그인을 같은 긴급 대상으로 적지 않습니다.

### BOD 문구가 페이지마다 다릅니다

KEV 항목은 아직 BOD 22-01을 적습니다. BOD 26-04 본문은 BOD 22-01을 폐지했다고 적습니다. 미국 FCEB가 아닌 조직은 2026-08-27 기한을 법정 의무로 옮기지 않습니다. 운영 일정은 KEV 카탈로그 항목을 다시 연 기록을 남깁니다.

## 실무 체크리스트

1. 인터넷에서 도달할 수 있는 Oracle HTTP Server와 WebLogic 프록시 listen 주소를 목록화합니다.
2. Apache 플러그인과 IIS 플러그인, 현재 버전, 뒤쪽 WebLogic 대상을 기록합니다.
3. IIS는 12.2.1.4.0만 영향인지 Oracle Note 1과 대조합니다.
4. January 2026 CPU의 HTTP Server와 Proxy Plug-in 패치 문서를 엽니다.
5. 유지할 프록시와 끌 프록시를 나눈 뒤 변경 창과 대체 경로를 정합니다.
6. 예기치 않은 데이터 접근과 HTTP 프록시 로그 확인 책임을 지정합니다.
7. BOD 26-04 기한을 내부 마감으로 쓸지 여부와 승인자를 기록합니다.
8. 패치 또는 중지 후 불필요한 HTTP 수신과 프록시 잔존 여부를 확인합니다.
