## 한눈에 보기

Azure Local what’s-new 2608은 2026년 8월 하이퍼컨버지드 배포를 solution version 12.2608.1003.8로 적습니다. 같은 페이지는 OS 버전 26100.33296과 그 OS 또는 Windows Server 2025에 맞는 드라이버가 필요하다고 적습니다.

- 결정: 지금 준비만 할지, OEM 검증이 끝날 때까지 설치를 보류할지
- 전제: 이 릴리스는 준비 업데이트 워크플로와 Feature update 상태 Pending OEM Validation을 새로 둔다
- 미리보기: 포털로 노드 추가, Azure에서 GPU 관리, Azure Arc Site Manager는 미리보기로 남아 있다
- 범위: 2606 준비 글이나 2607 iSCSI GA 글의 재작성이 아니다

## 문제 상황

포털에 2608이 보인다고 설치를 승인하면, 준비만 끝난 상태와 OEM 검증 대기, 미리보기 기능이 한 변경 창에 섞입니다.

What’s-new 2608은 업데이트를 지금 준비하고 나중에 설치하는 워크플로를 이 릴리스에 둔다고 적습니다. Feature update에는 Pending OEM Validation 상태가 추가되어, OEM 검증이 끝나기 전에는 진행할 수 없다고 적습니다. 릴리스 정보는 12.2608.1003.8의 제공일을 2026-08-18로 두고, 신규 배포가 이 빌드를 쓴다고 적습니다. OS build는 26100.33296입니다.

릴리스 정보는 Solution Builder Extension을 쓰는 클러스터는 하드웨어 공급자가 검증을 끝낸 뒤에야 Feature release를 받는다고 적습니다. 이 과정은 Microsoft 공개 이후 몇 주가 걸릴 수 있고 공급자마다 다르다고 적습니다. 지원을 유지하려면 업데이트를 여섯 달 안에 설치하고, Feature update 전에 마지막 cumulative update를 먼저 설치하라고 적습니다.

알려진 문제 2608 뷰는 이 릴리스에 고정된 이슈가 없고, 2608 고유 알려진 이슈도 없다고 적습니다. 이전 릴리스에서 이어진 항목은 그대로 남아 있습니다. 포털의 우아한 Shut down과 Turn off는 2604 이상이 필요하고, 노드 추가 포털 경로와 GPU Management from Azure, Arc Site Manager는 미리보기입니다. 미리보기를 일반 공급으로 보지 않습니다.

## 지금 결정할 것

- 2608을 이번 창에서 준비만 할지, 설치까지 갈지
- Pending OEM Validation이 보이면 설치를 보류할지
- 드라이버가 26100.33296 또는 Windows Server 2025와 맞는지
- 포털 노드 추가, GPU 관리, Arc Site Manager를 미리보기 한계로 둘지
- 2606 준비 기준과 2607 iSCSI 결정을 이 창에 다시 넣지 않을지

## 의사결정 기준

### 준비 완료와 설치 승인을 같은 상태로 보지 않습니다

What’s-new는 준비와 나중 설치를 나눕니다. 준비가 끝났다고 설치 창이 열린 것은 아닙니다. 노드별 solution version, OS build, 드라이버를 기록한 뒤에만 설치를 승인합니다.

### Pending OEM Validation을 건너뛰지 않습니다

Feature update의 새 상태는 OEM 검증 대기입니다. 릴리스 정보는 SBE 클러스터가 공급자 검증 후에야 Feature release를 받는다고 적습니다. 포털에 2608이 보여도 OEM 검증 전 설치를 강행하지 않습니다.

### 미리보기 세 가지를 2608 GA로 합치지 않습니다

노드 추가 포털, GPU Management from Azure, Arc Site Manager는 미리보기입니다. Shut down과 Turn off는 2604 이상에서 포털이 제공하는 동작입니다. 미리보기 기능을 2608 설치 성공의 조건으로 두지 않습니다.

### 2606 준비 글과 2607 iSCSI 글을 다시 쓰지 않습니다

이 글은 2608 준비 창과 OEM 검증 상태만 가릅니다. 이전 릴리스의 저장소 모델이나 업데이트 경로 점검은 해당 글의 범위입니다. 2608 알려진 문제 페이지에 고유 항목이 없다고 해서 이전 릴리스 잔존 이슈를 없다고 보지 않습니다.

## 실무 체크리스트

1. 노드별 solution version, OS build, 드라이버를 12.2608.1003.8과 26100.33296에 대조합니다.
2. 현재 창이 준비인지 설치인지, Pending OEM Validation이 있는지 기록합니다.
3. SBE를 쓰면 공급자 검증이 끝났는지 릴리스 정보 안내와 같이 확인합니다.
4. Feature update 전에 마지막 cumulative가 설치됐는지 확인합니다.
5. 포털 Shut down과 Turn off를 쓸 클러스터가 2604 이상인지 적습니다.
6. 노드 추가 포털, GPU 관리, Arc Site Manager를 미리보기로 남길지 승인합니다.
7. 2608 고유 알려진 이슈가 없다는 문구와 이전 릴리스 잔존 항목을 같은 요청서에 붙입니다.
8. 설치 후 solution version과 OS build, 준비 상태 만료 여부를 확인합니다.

## 제외 범위

- Azure Local 2606 업데이트 준비 글, 2607 iSCSI SAN GA 글의 재작성
- HCI 공급자의 우열, 가격, 성능 비교
- 미리보기를 일반 공급으로 보는 해석
- OEM 검증 없이 설치해도 된다는 단정
- 무중단, 완료 시간, 하드웨어 호환성의 사전 보장
