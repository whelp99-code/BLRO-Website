## 한눈에 보기

Citrix DaaS Web sign-in 문서는 2026-08-18 날짜이고, Entra ID 기반 Windows 인증으로 가상 데스크톱에 로그온하거나 잠금을 풀 수 있다고 적습니다. 같은 페이지는 미리보기이며 지원이 없고 생산에 아직 권하지 않는다고 적습니다.

- 결정: 미리보기 Web sign-in을 쓸지, Entra SSO 머신 정책만 쓸지, 둘 다 보류할지
- 전제: Windows 단일 세션 VDA 2607 이상, Workspace app Windows 2607 이상, Windows 11 24H2 KB5065789 이상 빌드 26100.6725
- 불일치: DaaS는 Entra joined 또는 Entra hybrid joined, 2607 LTSR 페이지는 hybrid joined만 적는다
- 범위: VDA 2607 Entra SSO 머신 정책 글의 재작성이 아니다

## 문제 상황

Entra 방법으로 데스크톱을 열면, 로그온·잠금 해제용 Web sign-in 미리보기와 세션 호스트 Entra SSO가 한 승인에 섞입니다.

DaaS Web sign-in은 기본으로 꺼져 있습니다. Citrix 정책의 Web sign-in을 배달 그룹에 적용합니다. 정책이 테넌트에 없으면 레지스트리 HKLM\SOFTWARE\Policies\Citrix\ICAPolicies의 AllowWebSignIn DWORD 1로 켤 수 있다고 적습니다. Entra SSO를 쓰는 것이 Web sign-in의 전제는 아니라고 같은 페이지가 못 박습니다. Entra SSO 문서의 Azure와 Entra 구성은 참고 단계로만 적혀 있습니다.

2607 LTSR Web sign-in 페이지도 2026-08-18 날짜이고 제목에 Preview를 붙입니다. 미리보기, 미지원, 생산 미권고는 DaaS와 같습니다. 시스템 요구의 세션 호스트 신원은 Entra hybrid joined만 적습니다. DaaS 페이지는 Entra joined 또는 Entra hybrid joined입니다.

DaaS What’s new는 페이지 last modified 2026-08-27이고, August 2026 항목에 Web sign-in Preview를 둡니다. Entra joined 또는 Entra hybrid joined 가상 데스크톱의 로그온과 잠금 해제를 적습니다. 온프레미스 조인 유형은 2607 LTSR 페이지와 같이 읽고, DaaS 한 줄로 평탄화하지 않습니다.

## 지금 결정할 것

- 대상이 Citrix DaaS인지, 온프레미스 2607 LTSR인지
- Web sign-in 미리보기를 생산 창에 넣을지, 파일럿만 할지
- Entra SSO와 별개로 둘지. Web sign-in은 Entra SSO가 필수가 아니다
- 세션 호스트를 Entra joined로 둘지, hybrid joined로 둘지. 두 문서가 다르게 적는다
- 정책이 없으면 레지스트리 AllowWebSignIn을 쓸지

## 의사결정 기준

### Web sign-in과 Entra SSO를 한 기능으로 보지 않습니다

Web sign-in은 로그온과 잠금 해제에 Entra 방법을 쓰는 자격 증명 공급자입니다. Entra SSO 머신 정책은 다른 글의 범위입니다. DaaS 문서는 Entra SSO를 쓰지 않아도 Web sign-in을 쓸 수 있다고 적습니다. 한 승인으로 두 기능을 켜지 않습니다.

### 미리보기와 미지원을 생산 승인에서 빼지 않습니다

DaaS와 2607 LTSR 본문은 모두 미리보기이며 지원이 없고 생산에 권하지 않는다고 적습니다. What’s new August 2026도 Preview로 표시합니다. 미리보기 한계를 빼고 일반 공급처럼 보고하지 않습니다.

### 조인 유형 불일치를 남깁니다

DaaS Web sign-in과 What’s new는 Entra joined 또는 Entra hybrid joined를 적습니다. 2607 LTSR Web sign-in은 hybrid joined만 적습니다. 제어면이 온프레미스이면 2607 LTSR 페이지를 기준으로 읽고, DaaS 문구로 조인 유형을 넓히지 않습니다.

### 최소 빌드와 기본 꺼짐을 확인합니다

두 Web sign-in 페이지는 Windows 단일 세션 VDA 2607 이상, Workspace app Windows 2607 이상, Windows 11 24H2 KB5065789 이상 빌드 26100.6725를 요구합니다. 기능은 기본으로 꺼져 있습니다. 정책 또는 AllowWebSignIn을 켠 호스트만 대상에 넣습니다.

## 실무 체크리스트

1. 제어면을 DaaS와 온프레미스 2607 LTSR로 나눕니다.
2. 세션 호스트 조인 유형을 DaaS 문구와 2607 LTSR 문구로 각각 기록합니다.
3. VDA, Workspace app, OS 빌드를 최소 요구와 대조합니다.
4. Web sign-in을 파일럿할지 생산에 넣지 않을지 미리보기 문구와 같이 승인합니다.
5. Entra SSO를 이미 쓰는지, Web sign-in만 켤지를 분리합니다.
6. 정책 적용 대상 배달 그룹과, 정책이 없을 때 AllowWebSignIn 사용 여부를 적습니다.
7. Entra에서 켜 둔 인증 방법이 로그온·잠금 화면에 보이는지 시험 책임을 정합니다.
8. 미리보기 미지원을 변경 요청서에 남기고, Entra SSO 글과 중복 승인하지 않습니다.
