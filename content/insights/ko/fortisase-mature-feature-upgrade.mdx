## 한눈에 보기

FortiSASE는 Mature 인스턴스에서 New major features available 모범 사례를 적용해야 Feature 기능이 열립니다. 25.2.c 이후 신규 인스턴스는 Feature가 기본입니다.

- 결정: 지금 Mature를 유지할지, 유지보수 창을 열고 Feature로 올릴지
- 창: 월요일 00:00부터 금요일 23:59 UTC, 주요 공휴일 제외. 보안 PoP 수에 따라 1시간에서 3시간
- 불일치: 업그레이드 후 버전 툴팁을 7.4로 적는 페이지와 Feature로 적는 페이지가 있음
- 범위: Prisma Access 에이전트 없는 접근이나 ION 양자내성 글이 아니라 FortiSASE 인스턴스 유형

## 문제 상황

FortiSASE 포털의 업그레이드 알림을 일반 패치처럼 승인하면, 사용자 트래픽 중단과 DNS 프로토콜 변경과 전용 공인 IP가 한 창에 섞입니다.

Mature 관리 가이드는 감사 페이지에 New major features available가 나타나면 유지보수 창과 인프라 업데이트가 필요하다고 적습니다. 그 창 동안 사용자 트래픽이 영향을 받습니다. 적용 가능 시간은 월요일 00:00부터 금요일 23:59 UTC이고 주요 공휴일은 제외됩니다. 그 밖에는 단계 링크가 비활성입니다. 보안 PoP가 8개 이하면 1시간, 9개에서 16개면 2시간, 16개를 넘으면 3시간으로 안내합니다.

Standard 구독이고 전용 IP가 없으면, 인가된 FortiExtender나 LAN 확장 FortiGate를 먼저 해제해야 합니다. 같은 조건이면 업그레이드가 전용 공인 IP를 추가 라이선스 없이 켭니다. 원격 VPN과 에지 장치 사용자 식별도 켜집니다. 기본 원격 사용자 IP 범위는 100.65.0.0/16입니다. 기존 온램프 터널은 업그레이드 후 재설정이 필요할 수 있습니다.

업그레이드 후 Standard이고 전용 IP가 없었던 인스턴스는 보안 웹 게이트웨이 포트가 9443으로 바뀝니다. 사용자 지정 PAC나 PAC 없는 프록시는 클라이언트를 고쳐야 합니다. SSL VPN 인스턴스 일부는 DNS가 UDP 대신 TLS와 HTTPS를 씁니다. VPN DNS와 SWG·에지 DNS가 다르면 이름 해석이 갈립니다. 암시적 DNS 규칙은 VPN 쪽 서버로 덮입니다.

릴리스 노트 소개는 이 문서를 FortiSASE 26.2.2.b 곧 7.4의 새 기능과 알려진 문제로 안내합니다. Feature 관리 가이드 26.1.73은 업그레이드 후 툴팁이 Feature를 보여 준다고 적습니다. Mature 가이드는 업그레이드 후 툴팁이 7.4를 보여 준다고 적습니다. 운영 승인은 포털 툴팁과 릴리스 번호를 같은 기록에 남깁니다.

## 지금 결정할 것

- Mature를 유지할지, Feature 기능을 위해 모범 사례 업그레이드를 할지
- 유지보수 창을 UTC 평일로 잡을지. 공휴일에는 진행할 수 없음
- Standard 구독에서 에지 장치를 먼저 해제할지
- SWG 포트 9443과 PAC 파일 수정을 같은 창에 넣을지
- SSL VPN DNS를 DOT와 DOH로 둘지, UDP 53으로 되돌릴지

## 의사결정 기준

### Mature와 Feature를 버전 숫자만으로 합치지 않습니다

25.2.c 이후 신규 인스턴스는 Feature가 기본입니다. 기존 Mature는 감사 페이지의 모범 사례를 적용해야 Feature 전용 기능이 열립니다. Feature 가이드는 에이전트 기반 ZTNA, 예약 업그레이드 슬롯, IPsec 전제 기능을 목록으로 둡니다. Mature에 없는 기능을 이미 쓸 수 있다고 적지 않습니다.

### 창과 트래픽 영향을 숨기지 않습니다

가이드는 사용자 트래픽이 창 동안 영향을 받는다고 적습니다. PoP 수에 따라 안내 시간이 다릅니다. 권장 단계를 빼면 마이그레이션이 막힙니다. 확인 창에서 영향을 이해한다고 눌러야 예약됩니다.

### DNS와 프록시 포트를 터널과 따로 적습니다

SSL VPN 시나리오에서 VPN DNS와 SWG·에지 DNS가 달랐다면, 업그레이드 후 한쪽으로 덮입니다. DOT와 DOH를 지원하지 않는 DNS는 UDP 53을 다시 켜야 합니다. SWG 포트 9443은 Standard이고 전용 IP가 없었던 경로의 후속 작업입니다. 전용 IP가 이미 있는 인스턴스에 같은 포트 변경을 단정하지 않습니다.

### 툴팁 표기가 페이지마다 다릅니다

Mature 가이드는 업그레이드 후 7.4를 보여 준다고 적습니다. Feature 가이드는 Feature를 보여 준다고 적습니다. 릴리스 노트는 26.2.2.b를 7.4로 부릅니다. 적용 확인은 포털 왼쪽 아래 툴팁과 릴리스 노트 번호를 같이 기록합니다.

## 실무 체크리스트

1. 인스턴스를 Mature, Feature, 25.2.c 이후 신규로 표시합니다.
2. 보안 PoP 수, Standard 여부, 전용 IP, 에지 장치 인가를 기록합니다.
3. UTC 평일 창과 공휴일 제외를 변경 달력에 넣습니다.
4. 온램프 터널 재설정과 원격 사용자 IP 범위 100.65.0.0/16 변경 필요를 적습니다.
5. PAC 파일과 SWG 포트 9443 대상 사용자를 나눕니다.
6. SSL VPN DNS가 DOT와 DOH를 쓰는지, UDP 53으로 되돌릴지를 정합니다.
7. Feature 전용 기능 중 이번에 쓸 항목만 승인 범위에 넣습니다.
8. 업그레이드 후 툴팁, 공인 IP 허용 목록, 메일 안내 수신자를 확인합니다.

## 제외 범위

- Prisma Access 에이전트 없는 접근 글이나 Prisma SD-WAN ION 양자내성 글의 재작성
- SASE와 SD-WAN 역할 구분 글의 재작성
- 특정 SASE 제품의 우열, 가격, 성능 비교
- 업그레이드가 보안 효과를 높이거나 무중단이라는 보장
- 고객별 테넌트, 계정, 웹훅, 전용 IP의 공개
