# 생성 이미지 자리 (오모냥이 생성 예정)

이번 세션의 자식 작업에는 이미지 생성 도구가 없었다. 아래는 표준 품질, 로고·문자·식별 가능한 사람 없음, 한국 기업 IT 톤. 프로토타입에는 같은 주제를 설명용 SVG로 그려 두었다. 사진이 생기면 SVG를 교체하고 캡션 `생성 이미지(분위기 연출용, 실제 사례 아님)`를 유지한다.

1. `images/01-aisle.png` — 창이 없는 데이터센터 통로. 따뜻한 종이색 조명, 딥 네이비그린 랙 실루엣, 텍스트·로고·사람 없음. 35mm, 얕은 심도, 사진.
2. `images/02-ops.png` — 운영실. 책상과 꺼진 모니터 여러 대, 빈 의자, 사람 없음. 구리빛 스탠드, 종이 문서. 로고·문자 없음.
3. `images/03-bench.png` — 엔지니어 작업대. 케이블, 라벨 없는 장비, 손 없음. 청회색 금속과 따뜻한 나무. 문자 없음.
4. `images/04-abstract.png` — 추상 인프라. 종이 위 먹선으로 된 노드와 선. 브랜드 마크 없음.
5. `images/05-migration.png` — 이전 작업 중인 빈 랙 열. 포장재와 빈 슬롯. 사람·로고·문자 없음.

제조사 제품 사진은 저장소에 라이선스 파일이 확인되지 않아 사용하지 않는다. 슬롯 문구: `제조사 공식 이미지 사용 허가 필요`.
