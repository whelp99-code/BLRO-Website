# BLRO 공개 후 90일 실행 로드맵

> 작성일: 2026-07-15  
> 이 문서는 `blro-master-website-growth-plan.md`를 변경하지 않는 공개 후 실행 보드다.

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 운영 웹 | 완료 | `https://blro.co.kr`, `https://www.blro.co.kr` HTTPS 200 확인 |

## 우선순위

### P1. 운영 수락 검증 — 즉시, 1일

목적: 첫 실제 고객 문의가 유실되지 않는지 확인한다.

1. 운영 도메인에서 synthetic inquiry 1건을 제출한다. 테스트 값은 명확히 `BLRO launch canary`로 표시하고, 실명·고객 정보는 사용하지 않는다.
2. Turnstile 통과, D1 암호화 저장, Queue 처리, `#blro-leads`의 마스킹 알림을 순서대로 확인한다.
3. HCI 체크리스트 요청도 동일하게 수행해 15분 만료 다운로드 URL과 R2 파일을 확인한다.
4. `/`, `/solutions`, `/contact`, `/insights`, 320px·768px·1440px의 핵심 화면을 실제 운영 도메인에서 확인한다.
5. 실패 시 lead ID와 Worker 로그만 사용해 원인을 찾고, 고객 데이터 재전송은 하지 않는다.

완료 기준: 문의·체크리스트 각 1건이 Slack에 마스킹되어 도착하고, 운영 화면·다운로드·오류 메시지가 정상이다.

### P2. 검색 기반 만들기 — 1주차

목적: 검색 엔진이 BLRO의 실제 공개 URL과 핵심 서비스를 올바르게 인식하게 한다.

1. Google Search Console에 `blro.co.kr` 도메인 속성을 인증하고 `https://blro.co.kr/sitemap.xml`을 제출한다.
2. 네이버 서치어드바이저에 사이트를 등록하고 동일 sitemap을 제출한다.
3. `www.blro.co.kr`은 `blro.co.kr`로 301 통일한다. canonical과 실제 주소를 하나로 맞춘다.
4. Organization, WebSite, Service, Article, Breadcrumb 구조화 데이터를 실제 운영 URL로 검사한다.
5. 검색 등록 후 기준선을 기록한다: 색인 URL 수, 노출, 클릭, 상위 검색어, 상위 랜딩페이지.

완료 기준: 두 도구에서 소유권 인증·sitemap 수신을 확인하고, 중복 `www` URL이 남지 않는다.

### P3. 리드 전환 경로 다듬기 — 1~2주차

목적: 방문자가 상담의 결과물을 이해하고 부담 없이 요청하게 한다.

1. 첫 리드 자산인 HCI·가상화 전환 사전진단 체크리스트를 홈페이지·관련 인사이트·상세 솔루션 페이지에 연결한다.
2. Contact 페이지에 "상담 후 받는 것"을 범위·판단 기준·다음 검증 단계로 명시한다. 확인되지 않은 SLA·고객 성과는 쓰지 않는다.
3. 폼 전환 퍼널을 비식별 이벤트로 기록한다: CTA 클릭 → 폼 시작 → 오류/Turnstile 실패 → 접수/다운로드.
4. 개인정보 처리방침의 보관 기간·수신 목적·문의 대응 담당자 문구를 실제 운영 결정에 맞춘다.

완료 기준: 모든 핵심 CTA가 상담 또는 체크리스트 한 경로로 연결되고, PII 없는 퍼널 신호를 주간 단위로 볼 수 있다.

### P4. 매일 2건의 승인형 콘텐츠 운영 — 2~6주차

목적: 단발성 홈페이지를 지속적으로 신뢰와 검색 유입을 쌓는 채널로 바꾼다.

1. 비공개 `#blro-content-review`에 매일 두 개의 후보를 게시한다: 리서치 질문, 1차 출처, 실무 판단, 관련 솔루션, CTA, 공개 위험.
2. 승인된 원문만 `/insights`에 공개한다. VMware·Nutanix 내부 비교, 고객 식별 정보, 미승인 벤더 우위 주장은 공개하지 않는다.
3. 승인 원문 하나를 네이버 블로그 요약, LinkedIn 의사결정 포스트, 3~7분 영상 스크립트, Threads·Instagram 카드로 재활용한다.
4. 각 채널 URL에는 UTM을 통일하고, 원문·체크리스트·상담 중 하나의 CTA만 둔다.

완료 기준: 매일 2개 후보, 주 2개 이상 승인 공개, 모든 공개 글의 출처·승인·CTA가 추적된다.

### P5. 주간 성장 리뷰 — 2주차부터 반복

목적: 콘텐츠 양이 아니라 유효 상담으로 개선 우선순위를 정한다.

매주 같은 시간에 아래를 한 장으로 검토한다.

| 지표 | 판단 질문 |
| --- | --- |
| 유입 채널·랜딩페이지 | 어떤 문제·검색어가 실제 방문을 만드는가 |
| CTA 클릭률·폼 시작률 | 무엇이 관심을 만들고 어디에서 이탈하는가 |
| 접수·유효 상담 수 | 어떤 콘텐츠가 실제 대화로 이어지는가 |
| 체크리스트 요청·다운로드 | 리드 자산의 주제가 맞는가 |
| 인덱싱·노출·클릭 | 다음 콘텐츠 클러스터를 어디에 투자할 것인가 |

완료 기준: 매주 하나의 개선 가설과 하나의 다음 주 콘텐츠 우선순위를 결정한다.

## 권장 실행 순서

`P1 운영 수락 검증 → P2 검색 등록 → P3 리드 전환 경로 → P4 콘텐츠 승인 루프 → P5 주간 리뷰`

P1이 끝나기 전에는 외부 유료 광고를 시작하지 않는다. 먼저 유입이 상담까지 도달하는지, 그 신호를 안전하게 측정할 수 있는지를 확인한다.
