# 상승효과 솔루션 지도

제품을 많이 묶는 것이 아니라, 한 제품으로 해결되지 않는 고객결과를 완성하는 조합만 남긴다.

## 1. VMware 전환 안전 패키지

### 고객 문제

비용이나 계약 때문에 VMware 대안을 검토하지만, 앱 호환·이전 중단·복구·운영인수 위험 때문에 결정을 미룬다.

### 제공 결과

- 이전 대상과 유지 대상 분류
- SCMT 이전·동기화 PoC
- VMware 백업과 HCI·vCenter 복구 시험
- 장애·롤백 시나리오
- 90일 전환계획과 역할표
- 3년 비교비용과 중단조건

### 파트너 상승효과

- Veeam: 혼합환경·불변백업·복구검증. 네이티브 지원은 GA 확인 후 포함한다.
- HCL 하드웨어 업체: 공급·부품·현장지원 책임을 명확히 한다.
- 애플리케이션 업체: 공식 지원과 전환 리허설을 공동 확인한다.

## 2. 제조·CAD 보안 워크스페이스

### 고객 문제

CAD·CAE·생산 앱과 대용량 설계데이터를 원격에서 사용해야 하지만 외부 반출, GPU 성능과 주변기기 호환이 걱정된다.

### 제공 결과

- 사용자·앱·GPU 프로파일
- NVIDIA vGPU 기반 대표 워크로드 PoC
- 파일전송·클립보드·인쇄·USB 정책
- 원격접속 ZTG와 장애대응
- VDI 이미지·데이터 복구시험

### 파트너 상승효과

- NVIDIA: 공식 vGPU 라이선스·GPU·드라이버·지원 앱 검증
- CAD·CAE ISV: 앱 버전·GPU·가상환경 지원 확인
- 단말·주변기기 업체: 스캐너·프린터·3D 마우스 등 실제 호환 검증

## 3. 글로벌 지사 보안접속

### 고객 문제

본사, 해외지사, 원격사용자의 SaaS·사내앱 경로가 다르고 회선·보안·클라우드팀 사이에서 장애책임이 분산된다.

### 제공 결과

- 국가·앱별 현재 경로와 품질 기준
- Athena SASE·CBTA·Secure SD-WAN 파일럿
- ZTG·ZTDP 접근·데이터 정책
- 장애연락·전환·원복 책임표
- 지점별 단계전환계획

### 파트너 상승효과

- 국내외 통신사·ISP: 마지막 구간과 현지 장애대응
- 고객 IdP: 사용자·그룹·장치 기반 접근정책
- SaaS·클라우드 사업자: 서비스 엔드포인트와 데이터 경로 검증

## 4. 경량 SOC 운영

### 고객 문제

방화벽·백신·로그는 많지만 전담인력 부족으로 실제 사고의 우선순위와 대응이 느리다.

### 제공 결과

- 현재 경보·사고·책임 흐름
- NGFW·EPP·NDR·XDR 연결 파일럿
- MDR 에스컬레이션과 고객 승인 경계
- 사고분류·차단·복구 런북
- 월간 보안운영 보고

### 파트너 상승효과

- ITSM·SIEM: 티켓, 승인, 장기로그와 감사 증거. 지원 통합목록을 먼저 확인한다.
- 백업·복구 업체: 랜섬웨어 차단 이후 깨끗한 복구로 연결한다.
- 보험·컴플라이언스 자문: 운영 증거를 요구조건에 맞추되 법률의견은 별도다.

## 5. 사이버 복구 증명

### 고객 문제

백업은 매일 성공하지만 실제 공격 후 어떤 복구지점이 깨끗하고 언제 업무가 재개될지 알 수 없다.

### 제공 결과

- 업무별 RPO·RTO와 복구순서
- 불변·오프사이트·권한분리 점검
- 랜섬웨어·사이트 장애 복구훈련
- 데이터 정합성·앱 기동·사용자 인수 증거
- 분기별 재훈련 계획

## 경쟁사이면서 파트너가 될 수 있는 경우

- Veeam은 HCI 내장백업의 경쟁 대안이지만 혼합환경·불변성·복구검증을 보완할 수 있다.
- Microsoft는 Azure Local·AVD 경쟁사지만 AD·M365·아이덴티티·앱 생태계에서는 필수 연계 대상이다.
- 기존 VMware는 전환 대상이면서 aHM·hDR·단계 이전을 위한 공존 플랫폼이다.
- 통신사는 회선 품질 문제의 책임주체이면서 SASE 완성도를 높이는 필수 파트너다.
