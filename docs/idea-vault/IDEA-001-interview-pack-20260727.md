# IDEA-001 고객 인터뷰 패키지

## 목표

최근 기술투자 결정을 경험한 담당자 3명에게 의사결정 지연 원인과 유료 파일럿 구매 조건을 확인한다.

## 모집 기준

- 인프라·보안·디지털전환 책임자 또는 구매 결정에 참여한 실무 리더
- 최근 12개월 내 HCI/VDI/DR/SASE/보안/AI 인프라 검토 경험
- 특정 벤더의 홍보 인터뷰가 아닌 실제 선택·보류·PoC 경험

## 30분 질문

1. 최근 가장 오래 걸린 기술 결정은 무엇이었나?
2. 결정을 늦춘 증거·이해관계자·비용 항목은 무엇이었나?
3. 벤더·총판·파트너 제안이 서로 달랐던 부분은 무엇이었나?
4. PoC가 구매로 이어지지 않은 이유는 무엇이었나?
5. 경영진이 최종 승인 전에 요구한 표와 근거는 무엇이었나?
6. 3주 안에 결정안·비교표·PoC 기준을 받는다면 어떤 조건에서 비용을 지불하겠나?
7. 결과물이 실패했다고 판단할 기준은 무엇인가?

## 기록 규칙

- 고객명·연락처·비공개 구성은 이 저장소에 기록하지 않는다.
- 인터뷰 ID, 역할군, 산업군, 문제·트리거·원하는 결과·구매 조건만 익명화해 기록한다.
- 한 사람의 표현을 시장 전체의 사실로 일반화하지 않는다.

## 승격 기준

- 동일 문제를 서로 다른 3명에게서 확인
- 최소 1명이 유료 파일럿 범위·가격·일정을 구체적으로 요청
- 고객이 원하는 완료조건을 1페이지로 합의 가능
