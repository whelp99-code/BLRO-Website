# IDEA-001 — 인터넷 광고 기반 고객 인터뷰 3명 모집안

## 목표

광고 클릭 수가 아니라 **검증 가능한 기술투자 의사결정 경험자 3명**을 모집한다. 인터뷰 자체가 목적이 아니라 `IDEA-001 3주 기술투자 의사결정 패키지`의 유료 파일럿 구매 조건을 확인하는 것이 목적이다.

## 모집 오퍼

### 광고 문구

> VMware·HCI·VDI·보안 전환을 실제로 검토해 본 IT 책임자 3명을 모집합니다. 30분 비공개 인터뷰 후, 의사결정 지연 원인과 PoC 기준을 익명화해 정리합니다. 영업 발표가 아닌 실무 경험 인터뷰입니다.

### 참여자 혜택

- 30분 비공개 인터뷰
- 인터뷰 후 익명화된 `기술투자 결정 체크리스트` 1부
- 예산 승인 후 5만원 상당 참여 보상 또는 동일 가치의 BLRO 진단 세션
- 특정 제품 구매·계약·추천을 요구하지 않음

참여 보상은 광고 게시 전 사업·세무·개인정보 검토를 거친다. 보상을 지급할 수 없으면 광고에서 약속하지 않는다.

## 타깃 세그먼트

| 세그먼트 | 모집 조건 | 광고 메시지 |
| --- | --- | --- |
| HCI/VMware | 최근 12개월 내 갱신·이전·HCI 검토 경험, 인프라 책임자 | “제품 비교보다 이전·복구·롤백 기준을 먼저 정했는가?” |
| VDI/CAD | 제조·설계·콜센터 VDI, GPU·주변기기·반출통제 경험 | “VDI PoC가 실제 구매로 이어지지 않은 이유는?” |
| 보안/SASE/DR | 지사망·보안운영·복구훈련 의사결정 경험 | “장애·복구·보안 책임 경계가 제안서에 남아 있는가?” |

최종 3명은 한 세그먼트에 몰지 않고 최소 2개 세그먼트로 분산한다.

## 채널 믹스 — 14일 검증

### 1순위: 네이버 검색광고 60%

고의도 검색어만 사용한다.

- `VMware 마이그레이션 컨설팅`
- `VMware 대체 검토`
- `HCI 전환 PoC`
- `VDI 구축 검토`
- `랜섬웨어 복구 훈련`
- `SASE 지사망 검토`

제외어: `취업`, `교육`, `자격증`, `중고`, `무료 다운로드`, `채용`, `개인용 PC`, `게임`.

### 2순위: LinkedIn Sponsored Content 30%

한국·IT서비스·중견/대기업·Manager 이상을 기본으로 하고, 직함과 직무를 조합한다.

- 직함: CIO, CISO, IT Infrastructure Manager, IT Operations Manager, Cloud Architect, Network Manager, 보안팀장, 인프라팀장
- 직무: Information Technology, Engineering, Operations
- 산업: 제조, 금융, 의료, 공공, IT서비스
- 광고 목표: 클릭보다 Lead Generation 또는 Website Conversion

LinkedIn은 직함·직무·산업·회사 규모·seniority를 조합할 수 있으므로, 넓은 관심사 타깃보다 역할 기반 소규모 캠페인으로 시작한다. [LinkedIn 공식 타깃 안내](https://business.linkedin.com/advertise/ads/targeting) · [캠페인 목표 안내](https://business.linkedin.com/marketing-solutions/how-to-advertise-on-linkedin)

### 3순위: Google Search 10%

네이버에서 전환 신호가 있는 키워드만 재검증한다. 광범위한 Display·YouTube 광고는 이번 3명 모집에서 사용하지 않는다.

## 전용 랜딩페이지

기존 일반 문의폼을 그대로 광고에 연결하지 않는다. `/research-interview` 전용 페이지를 만든다.

### 첫 화면

**헤드라인:**

`기술투자 결정을 실제로 해본 IT 책임자 3명을 찾습니다.`

**서브카피:**

`30분 비공개 인터뷰로 HCI·VDI·보안·DR 전환에서 무엇이 결정을 늦추는지 확인합니다.`

### 신청 필드

- 역할군: CIO/CISO/인프라/보안/구매/운영
- 회사 규모 구간
- 최근 검토 영역: HCI/VDI/보안/SASE/DR
- 최근 의사결정 시점
- 결정에 참여한 정도: 정보 제공/실무 결정/최종 승인
- 인터뷰 가능 시간대
- 업무용 이메일·연락처
- 연구 목적 수집·이용 동의
- 별도 마케팅 수신 동의는 기본 해제

비밀자료 업로드, 고객명, 구성도, 가격표는 받지 않는다. 개인정보 처리 목적은 “시장 검증 인터뷰 연락 및 보상 처리”로 별도 고지한다.

## 심사 점수

| 기준 | 점수 |
| --- | ---: |
| 최근 12개월 내 관련 기술결정 | 0~3 |
| 최종 결정 또는 실질적 영향력 | 0~3 |
| BLRO 우선 세그먼트 일치 | 0~2 |
| PoC·예산·복구 기준을 설명할 수 있음 | 0~2 |

8점 이상만 인터뷰 예약한다. 같은 회사·같은 프로젝트의 중복 지원은 1명으로 계산한다. 광고 리드 수가 아니라 `qualified → booked → completed`만 KPI에 포함한다.

## 예산과 중단 게이트

| 항목 | 14일 상한 |
| --- | ---: |
| 네이버 검색 | 600,000원 |
| LinkedIn | 300,000원 |
| Google Search 재검증 | 100,000원 |
| 참여 보상 | 150,000원 |
| 총액 | 1,150,000원 |

중단 조건:

- 300,000원 사용 후 qualified 신청 0건
- 신청 10건 중 8건 이상이 취업·교육·제품구매 문의
- 예약률 30% 미만
- 인터뷰 1명 완료 후에도 구매 문제·완료조건이 전혀 반복되지 않음

확대 조건:

- 1주차에 qualified 3건 이상
- 세그먼트 2개 이상에서 신청 발생
- 인터뷰 2건 이상에서 같은 결정 지연 문제가 반복

## 14일 실행 순서

1. 1~2일차: 랜딩·동의문·심사표·이벤트를 준비하고 테스트 리드 1건으로 확인
2. 3~5일차: 네이버 HCI/VMware 캠페인만 시작, 검색어·제외어 조정
3. 6~8일차: LinkedIn 직함·seniority 캠페인을 별도 시작
4. 9~11일차: qualified 신청자 인터뷰, 광고 문구를 실제 표현으로 수정
5. 12~14일차: 세그먼트 균형을 맞춰 3명 확정, `IDEA-001` 유료 파일럿 제안

## 성공 기준

- 완료 인터뷰 3명
- 세그먼트 2개 이상
- 동일한 구매 장애 또는 결정 지연 원인 2건 이상 반복
- 최소 1명이 고정 범위·가격·일정을 구체적으로 문의
- 광고비·보상비·예약·완료·유료 제안 전환을 한 표에 기록

## 하지 않는 것

- “무료 컨설팅”, “절감 보장”, “특정 벤더 우위”를 광고하지 않는다.
- 고객명·성과 수치·파트너 등급을 광고 신뢰 근거로 사용하지 않는다.
- 일반적인 `IT 컨설팅` 광범위 키워드로 예산을 소진하지 않는다.
- 신청자에게 제품 데모나 영업 전화를 인터뷰 조건으로 요구하지 않는다.
