# IDEA-006 — `blro.kr` 고객 의사결정 워크스페이스

- 상태: 보류
- 우선순위: P3
- 최초 기록일: 2026-07-15
- 마지막 검토일: 2026-07-15

## 한 문장 제안

반복 서비스가 검증된 이후 고객이 진단자료, 선택지, 결정안, 승인, 실행상태를 한곳에서 관리하도록 `blro.kr`을 고객 업무공간으로 사용한다.

## 고객이 얻는 혜택

- 이메일과 개별 문서에 흩어진 의사결정 자료를 한곳에서 확인한다.
- 최신 결정안, 검토상태, 책임자와 다음 행동을 빠르게 파악한다.
- 경영진, 실무팀, BLRO, 파트너가 같은 기준과 버전을 본다.
- 프로젝트 종료 후에도 선택 근거와 실행 이력이 남는다.

## 가능한 기능

- 진단 질문과 자료 제출
- 선택지 비교표와 결정안 열람
- 검토·승인 상태와 다음 행동
- PoC 검증 결과와 실행 체크리스트
- 고객별 접근권한과 변경이력

## 보류 이유

- 현재 고객이 돈을 지불할 핵심은 도메인이나 포털이 아니라 의사결정과 운영 개선 결과다.
- 반복 업무와 접근권한 요구가 확인되지 않은 상태에서 개발하면 내부 관리도구에 그칠 수 있다.
- 공개 홈페이지 MVP에서는 고객 포털이 제외되어 있다.

## 재검토 조건

다음 조건을 모두 충족할 때 별도 제품기획을 시작한다.

- `IDEA-001` 또는 `IDEA-002`의 유료 수행 사례가 3건 이상 있다.
- 고객 2곳 이상이 자료·승인·상태 공유 공간을 반복적으로 요구한다.
- 공통 데이터 구조와 권한모델을 두 프로젝트 이상에서 재사용할 수 있다.
- 개발·보안·운영비용보다 고객 유지 또는 제공효율 효과가 크다는 근거가 있다.

## 도메인 역할

- `blro.co.kr`: 회사, 전문성, 인사이트, 문의를 위한 공개 신뢰 사이트
- `blro.kr`: 검증 후 고객 진단·결정·실행 업무공간 후보

도메인 구분이 사업전략을 결정하지 않는다. 검증된 고객업무가 도메인의 역할을 결정한다.
