# BLRO 아이디어 창고

기준일: 2026-07-15  
목적: 사업·상품·운영 아이디어를 고객가치 중심으로 축적하고, 검증된 아이디어만 실제 상품과 웹사이트에 반영한다.

## 운영 원칙

1. 도메인, AI, 포털 같은 수단보다 고객이 얻게 될 변화를 먼저 적는다.
2. 고객, 문제, 구매 결과, 측정 방법이 불명확한 아이디어는 상품으로 승격하지 않는다.
3. 절감률·성과 수치는 실제 고객 기준선과 결과가 생기기 전까지 약속하지 않는다.
4. 아이디어는 작게 검증하고, 유료 파일럿에서 반복 구매 가능성을 확인한다.
5. 검증되지 않은 아이디어를 홈페이지의 확정 사업처럼 공개하지 않는다.

## 현재 추천 실행 순서

1. `IDEA-001`을 실제 제안서와 첫 유료 파일럿으로 검증한다.
2. 기술 결정 이후 실행 지원이 필요한 고객에게 `IDEA-002`를 후속 제안한다.
3. 기존 글로벌 벤더 접점에서 `IDEA-003`의 구매 의사를 인터뷰한다.
4. 반복 수요가 확인되기 전에는 `IDEA-006`을 개발하지 않는다.

## 상품 승격 조건

아래 항목을 모두 충족하면 `상품화`로 변경한다.

- 동일하거나 유사한 문제를 가진 고객 인터뷰가 3건 이상 있다.
- 고객이 결과물보다 해결되는 문제와 변화에 가치를 둔다.
- 범위, 기간, 고객 협조사항, 완료조건을 한 페이지로 설명할 수 있다.
- 최소 1건의 유료 파일럿 또는 이에 준하는 구매 의사 증거가 있다.
- 효과를 측정할 기준선과 종료 시점의 지표가 있다.
- BLRO가 반복 제공할 수 있고, 책임 범위를 통제할 수 있다.
