# IDEA-001 첫 유료 파일럿 브리프

## 제안

`3주 기술투자 의사결정 패키지`를 특정 제품 판매가 아닌 독립적인 비교·검증·내부 승인 지원으로 제안한다.

## 첫 파일럿 대상

- 최근 3~6개월 안에 VMware/HCI, VDI, DR, SASE 또는 보안 투자를 결정해야 하는 기업
- CIO/CISO/인프라 책임자가 내부 보고와 PoC 범위를 동시에 책임지는 경우
- 현재 제안서가 제품·견적 중심이고, 비교 기준·탈락 조건·책임 경계가 비어 있는 경우

## 3주 산출물

| 주차 | 산출물 | 고객 확인 |
| --- | --- | --- |
| 1주차 | 현재 환경·결정 기준·위험 지도·필수 증거 목록 | 비교 가능한 선택지와 제외 조건 합의 |
| 2주차 | 2~3개 선택지 비교표·누락비용·PoC 통과/중단 기준 | 경영진 보고 초안 리뷰 |
| 3주차 | 1페이지 결정안·90일 실행계획·역할표 | 최종 의사결정 회의 |

## 구매 의사 검증

가격을 임의로 공개하지 않는다. 인터뷰에서 아래 중 하나를 확인하면 유료 제안 단계로 승격한다.

- 고정 범위·완료조건을 전제로 한 견적 요청
- 구매 담당자 또는 예산 책임자의 유료 파일럿 일정 협의
- 내부 보고에 사용할 결과물과 납기를 명시한 LOI 또는 이메일 확인

## 중단 조건

- 1주차에 비교 가능한 기준과 고객 제공자료가 합의되지 않음
- BLRO가 책임질 수 없는 법률·회계·성능 보증을 요구함
- 고객이 결과물·검증 기준보다 특정 제품 구매 확정만 요구함
