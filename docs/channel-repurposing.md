# 콘텐츠 채널 전환 기준

원문은 승인된 BLRO 인사이트만 사용한다. 같은 주장이라도 채널별 형식에 맞춰 줄이며, 새로운 고객 사례·수치·벤더 비교 결론을 덧붙이지 않는다.

| 채널 | 형식 | 필수 요소 | CTA |
| --- | --- | --- | --- |
| 홈페이지 | 원문·상세 SEO 페이지 | 출처, 판단 질문, 공개 승인 | 전환 진단 상담 |
| 네이버 블로그 | 900~1,500자 요약 | 문제 상황, 3~5개 질문, 원문 링크 | 원문 또는 상담 |
| LinkedIn | 의사결정 관점 포스트 | 현장 신호, 판단 기준, 한 가지 반론 | 원문 링크 |
| YouTube | 3~7분 스크립트 | 문제, 검증 순서, 주의점, 화면 근거 | 원문 링크 |
| Threads·Instagram | 5~7장 슬라이드 또는 짧은 문장 | 한 질문·한 기준·한 결론 | 원문 링크 |

## UTM

`utm_source`, `utm_medium`, `utm_campaign`만 사용한다. 개인 이름, 회사명, 이메일, 전화번호, 메시지는 URL 또는 분석 이벤트에 넣지 않는다.
