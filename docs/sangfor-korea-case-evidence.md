# Sangfor 한국 공개 사례 근거 장부

확인일: 2026-07-17

## 공개 경계

- 이 문서는 Sangfor 공식 한국어 사이트에 제조사가 공개한 사례만 정리한다.
- 고객명과 운영 상황은 각 원문의 범위 안에서만 사용한다.
- BLRO가 해당 프로젝트를 수행했거나 특정 성과를 보증한다는 표현은 사용하지 않는다.
- 원문에서 독립 검증할 수 없는 성능 수치와 정량 성과는 홈페이지에 옮기지 않는다.

## 제외한 주장

- BLRO의 구축 실적, 파트너 등급 또는 공식 총판 지위를 암시하는 문장
- 제조사가 제시한 정량 성능·절감률을 BLRO가 검증한 것처럼 보이는 문장
- 고객의 현재 운영 상태가 공개 당시와 동일하다는 주장
- 해당 제품이 모든 환경에 적합하거나 동일한 결과를 낸다는 보장
